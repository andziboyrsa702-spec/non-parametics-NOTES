# STA2020 Non-Parametric Statistical Techniques

Interactive study notes for the full STA2020 non-parametric techniques chapter.

## Included
- Introduction to non-parametric methods and data types
- Ranking and ties
- Wilcoxon Signed Rank Sum Test
- Sign Test
- Wilcoxon Rank Sum / Mann–Whitney
- Kruskal–Wallis
- Friedman Test
- Spearman Rank Correlation
- Test-selection guide
- Exam-answer workflow
- RStudio code integrated with the theory

The teaching structure follows the companion STA2020 ANOVA Notes approach: concept → assumptions → hypotheses → calculation → R → interpretation → summary.
