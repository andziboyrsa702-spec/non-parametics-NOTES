Kruskal–Wallis Test

Kruskal–Wallis extends rank-based comparison to more than two independent groups. In STA2020 it is the non-parametric counterpart of a single-factor (one-way) ANOVA.

In plain language: Kruskal–Wallis asks whether three or more independent groups appear to be centred in the same place. It is the non-parametric counterpart of single-factor / one-way ANOVA in the supplied notes.

6.1 Conditions

The observations are ordinal or quantitative and need not be normal; treatment levels and observations within treatment levels are independent; there are at least three observations per sample; and population distributions differ only in location if they differ.

6.2 Hypotheses

(H_0): the locations of all (k) populations are the same. (H_1): at least two population locations differ.

6.3 Test statistic

Pool all observations, rank from smallest to largest, average tied ranks and obtain rank sums (T_1,ldots,T_k). With total sample size (n_T),

\[H=\frac{12}{n_T(n_T+1)}\sum_{i=1}^{k}\frac{T_i^2}{n_i}-3(n_T+1).\]

When the null is true, ranks should be distributed fairly evenly among groups and (H) should be relatively small.

For the course conditions, \(H\) is compared with an upper-tail chi-squared distribution with \(k-1\) degrees of freedom. Reject \(H_0\) when \(H\) is sufficiently large or when the p-value is at most \(\alpha\).

6.5 Why Kruskal–Wallis is the natural extension

For two independent groups, Rank Sum asks whether one group tends to receive systematically larger ranks. With three or more independent groups, Kruskal–Wallis uses the same basic idea but tracks a rank sum for every group. If (H_0) is true, the groups should receive a reasonably balanced share of low, middle and high ranks. If one or more groups accumulate unusually high or low ranks, (H) increases.

The test is therefore not “ANOVA on the original observations.” The raw observations are first converted to ranks, and the between-group separation is assessed through those ranks.

6.6 EDA first, test second

Your supplied Kruskal–Wallis R file performs exploratory data analysis before calling kruskal.test(): it draws a boxplot and uses Q–Q plots for each group. This is a useful learning habit because the graph tells you what the groups look like, while the formal test tells you whether the observed rank separation is statistically convincing.

Lecture 4 R workflow
boxplot(kw1$num ~ kw1$name,
        main = "Boxplot of shifts and speed",
        xlab = "Shifts", ylab = "Speed")

qqnorm(kw1$num[kw1$name=="mid.eight"])
qqline(kw1$num[kw1$name=="mid.eight"])

kruskal.test(num ~ name, data = kw1)

6.7 Manual calculation in R

The code reproduces the hand method
kw1$rank <- rank(kw1$num, ties.method = "average")
T1 <- sum(kw1$rank[kw1$name == "four.mid"])
T2 <- sum(kw1$rank[kw1$name == "mid.eight"])
T3 <- sum(kw1$rank[kw1$name == "eight.four"])

n <- nrow(kw1)
H <- (12/(n*(n+1))) *
     (T1^2/n1 + T2^2/n2 + T3^2/n3) -
     3*(n+1)

pchisq(H, df = 2, lower.tail = FALSE)
Why is the chi-square test upper-tailed?

Under (H_0), balanced ranks make (H) small. Evidence against (H_0) comes from unusually uneven rank sums, which make (H) large. Therefore the rejection region is in the upper tail.

6.8 Direct R test

R — Kruskal–Wallis
kruskal.test(response ~ group, data = dat)
