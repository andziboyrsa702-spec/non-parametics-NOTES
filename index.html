Preface

Welcome to the Non-Parametric Statistical Techniques section of STA2020.

These notes are organised to follow the learning outcomes, terminology, hand-calculation methods, examples and R workflows contained in the supplied STA2020 non-parametric lecture material. The aim is not merely to provide formulas. Each chapter develops the statistical reasoning behind the procedure and then connects that reasoning to calculation and interpretation.

The module begins with the foundations of non-parametric reasoning and ranking. It then develops the two-sample procedures, methods for more than two groups, and rank correlation before finishing with test selection, worked practice and exam preparation.

  1. Introduction to non-parametric techniques
  2. Ranking data and handling ties
  3. Wilcoxon Signed Rank Sum Test
  4. Sign Test overview
  5. Wilcoxon Rank Sum / Mann–Whitney Test
  6. Kruskal–Wallis Test
  7. Friedman Test
  8. Spearman’s Rank Correlation Test
  9. Choosing the correct procedure and exam workflow

Throughout the book, R code is presented alongside the statistical method so that you can see how the manual procedure and software implementation correspond. Running the supplied code yourself is strongly encouraged.

x <- c(1, 2, 3, 4, 5)
rank(x)
# [1] 1 2 3 4 5

The central question throughout these notes is: what should the ranks, signs or frequencies look like if the null hypothesis is true?
